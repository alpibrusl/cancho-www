Granite.
No mortar.

In La Pedriza, boulders the size of houses stay where they are by their own weight and what they touch. cancho is a language, and an ecosystem, built the same way: every piece says what it rests on, and the compiler checks it.

Watch it workExplore the ecosystem

Owned, not borrowed

Dependencies pin to content hashes. Nothing changes under you because a maintainer published a new version.

Bounded, not trusted

Foreign code is allowed, never hidden. cancho authority names what is reachable, and says “unbounded” when it can’t.

Agent-first

Diagnostics, the command tree and a skill file come out of the binary as data, with a rule tag instead of a sentence to parse.

The idea

Authority is a value, and you can watch it move.

split(world) is the only place a program gets authority from. Every piece must then be handed on or released; a function that was never given one cannot use it. Pick a story.

The two refusals are real rules the compiler reports (linear-value-unconsumed, effect-not-declared). The scenes are drawn, the rule tags are not.

The same map as a list
  • cancho (built): The language and its Rust compiler. A second compiler, written in cancho, is being checked against it.
  • cancho-ui (built): A UI language whose compiler knows what each component is allowed to do. Builds JavaScript and DOM.
  • cancho-hooks (alpha): Webhook delivery: on disk before the 202, signed, retried, dead-lettered and replayable.
  • cancho-cache (alpha): Redis-compatible string cache over RESP2/RESP3, expiry and LRU in a fixed arena.
  • cancho-gateway (design): An auditable HTTP/1.1 reverse proxy: a fixed upstream set proven by the authority report.
  • cancho-mqtt (design): An MQTT 3.1.1 broker: one thread, one poller, bounded memory.
  • cancho-dns (design): A forwarding and caching DNS resolver: bounded parser, fixed arena.
  • cancho-oci (design): Container images without a daemon: a deterministic OCI image builder and registry client.
  • cancho-pg (early): PostgreSQL client: v3 protocol, SCRAM-SHA-256, extended queries, TLS, non-blocking pool.
  • cancho-schema (early): Schemas as data: validation, problem+json errors and JSON Schema 2020-12 from one value.
  • cancho-web (early): Typed routes, validated bodies, problem+json errors and an OpenAPI document from one declaration.
  • cancho-log (early): A durable, segmented, append-only log with crash-safe recovery that cuts off a torn tail.
  • cancho-stats (design): Statistics on tabular data as a command line an agent can read: exact sums, tests, intervals, resampling.
  • cancho-ml (design): Classical ML, pipelines and evaluation: deterministic, bounded, agent-first.
  • cancho-tools (working): Nine small tools for agents: seek, list, peek, jsonq, tally, hash, write, replace, move. JSON out, errors that name a rule.
  • cancho-table (built): Select, filter, group and aggregate CSV/TSV for agents; bounded, exact, byte-stable.
  • cancho-robot (design): A robot arm controller: the Feetech servo bus, SO-101 kinematics and a safety core every motion goes through.
  • cancho-gpu (built): A compiler for lex-gpu's .lx tile kernels to CUDA C and Metal, written in cancho.

Recorded, not staged

See it refuse, then run.

Real terminals, real output; only the typing is simulated. A leaked file is refused by a named rule, one line fixes it, and the compiler says what the program may do. Then the same idea, lifted to a UI.

Deliberately not here

What was left out is the design.

garbage collectordestructorsexceptionsborrow checker implicit conversionsambient authoritytextual macrosproc macros

Borrowing is lexical: a region is a block, so a reference’s validity is read off the syntax. Io {} does not compile. Macros would break stable, content-addressable identity. The docs have the reasons.

Status: pre-1.0

  • Alpha and early products are built with it (see the map), each with an authority report the compiler derives. Alpha means it runs and may change.
  • The compiler is still the Rust one. The cancho compiler builds real programs but does not yet refuse everything the language refuses, so it is not the default.
  • Dependencies resolve end to end, and a real TLS handshake compiles and runs.
  • There is no manifest-level version string: a hash is what you depend on.
  • Claims that turn out wrong are corrected in place in the docs, not quietly edited.
